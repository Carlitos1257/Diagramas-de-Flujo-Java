## Organización

Cada capítulo contiene tres carpetas:
- `analisis_requerimientos/`: objetivo, entradas, proceso, salidas, requerimientos y algoritmo.
- `diagramas_drawio/`: diagramas editables para abrir en [diagrams.net](https://app.diagrams.net/).
- `java/`: programas fuente.

## Ejecutar un programa
1. Abrir la carpeta del ejercicio en Visual Studio Code.
2. Abrir una terminal en la carpeta `java`.
3. Compilar: `javac Ejercicio13.java`.
4. Ejecutar: `java Ejercicio13`.
5. Cambiar el número 13 por el ejercicio que se desea probar.

## Archivos de entrada
- Ejercicios 69 y 70: `empleados.txt`. Para el 69 el formato de línea es `nombre;año`; para el 70 es `nombre;edad;M/F`.
- Ejercicio 71: `categorias.txt`; el segundo campo contiene la categoría 1, 2 o 3.
