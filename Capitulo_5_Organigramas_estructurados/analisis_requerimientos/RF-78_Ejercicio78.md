# Ejercicio 78: Determinar si un número es positivo o negativo

**Capítulo:** Capitulo 5 Organigramas estructurados  
**Estudiante:** Jank Carlos Arias Pérez  
**Modalidad:** Individual

## Objetivo
Desarrollar un programa en Java que resuelva el ejercicio mediante instrucciones básicas de Programación 1.

## Entradas
Un número entero.

## Proceso
Comparar el número con cero para clasificarlo como positivo, negativo o cero.

## Salidas
Mensaje de clasificación del número.

## Requerimientos funcionales
1. Solicitar un número al usuario.
2. Comparar el número con cero.
3. Mostrar si el número es positivo, negativo o igual a cero.

## Requerimientos no funcionales
- Ejecutarse en consola con Java.
- Aceptar números enteros.
- Presentar una única clasificación para el valor ingresado.

## Requerimientos de dominio
- Un número mayor que cero es positivo.
- Un número menor que cero es negativo.
- El cero constituye un caso independiente; no es positivo ni negativo.

## Algoritmo
1. Inicio
2. Leer número
3. Si número > 0: positivo; si número < 0: negativo; en otro caso: cero
4. Fin
