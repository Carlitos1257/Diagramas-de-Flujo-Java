# Ejercicio 40: Sumar los diez primeros elementos de una lista

**Capítulo:** Capitulo 3 Trabajando con tablas

**Modalidad:** Individual

## Objetivo
Desarrollar un programa en Java que resuelva el ejercicio mediante instrucciones básicas de Programación 1.

## Entradas

## Proceso
Guardar cada elemento y acumular su valor en una variable suma.

## Salidas

## Algoritmo
1. Inicio
2. Crear arreglo de 10 posiciones; suma = 0
3. Leer cada elemento y acumularlo
4. Mostrar suma
5. Fin
